# Character decorations

Shimeji decorations are original hand-drawn SVG fan art. The 37 decoration embeds a cropped raster image of the official default character artwork.

- Shijima and Majime: *Shimeji Simulation*, characters by Tsukumizu. Reference: https://en.wikipedia.org/wiki/Shimeji_Simulation
- 37: *Reverse: 1999*, original character artwork © Bluepoch. Source: https://wiki.biligame.com/reverse1999/37 (立绘 37 01.png). Cropped and embedded in an SVG without repainting.

Unofficial, not endorsed by the original rights holders. The Shimeji SVG uses reduced-motion CSS. The 37 portrait is static and transparent.
